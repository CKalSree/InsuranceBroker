# Playwright review workflow

1. Inspect the current test setup and page objects.
2. Identify the user journey and expected outcomes.
3. Prefer role-based, label-based, or test-id locators.
4. Avoid arbitrary timeouts when a condition can be awaited.
5. Include negative and validation scenarios.
6. Run the relevant tests if available; report failures honestly.
